# muxy 0.119.11

## Default terminal fonts

Bundle JetBrains Mono 2.304 and the KR, JP, and SC regional subsets of Noto Sans CJK 2.004. Latin text and terminal symbols use JetBrains Mono. Hangul uses KR and kana uses JP. Shared Han characters follow the device language, with KR as the default for other languages. CN uses the Simplified Chinese SC face. Emoji and unsupported glyphs retain Android's system fallback.

Cell width comes from JetBrains Mono. CJK glyphs fit their terminal cell count, and row metrics include the CJK fonts. Zoom preserves the selected font stack. Existing `~/.termux/font.ttf` files still override the defaults and are not modified. Font binaries, source revisions, checksums, and redistribution licenses are included in the APK.

## Session menu

Add a persistent 48 dp session-menu button beside the terminal toolbar. It remains available when extra keys are hidden or empty, without covering terminal text or requiring an edge gesture. Existing swipe access, extra-key definitions, and shortcuts remain available. The button respects text-selection locking and updates its accessible label and keyboard focus when the drawer changes.

## Idle-session handling

Retry `waitpid()` after `EINTR` instead of interpreting uninitialized status as process exit. Report actual wait failures without generating false exit events. PTY reads retry interrupted operations, preserve partial output, and report non-transient failures. Closing the output queue preserves bytes already accepted until they are drained.

Acquire and release CPU and Wi-Fi locks independently, checking whether each lock is actually held. Missing or denied Wi-Fi locking no longer aborts terminal sessions or drops an acquired CPU lock. Notifications reflect partial acquisition. Wake locks remain user-controlled. This release does not inject SSH keepalive input or reconnect transports after network loss.

## Zoom crash

Clear both cells of a wide character when an alternate-screen width reduction clips its trailing cell. Previously, a leading half could remain at the right edge and fail native row validation during rendering. The fix retains the validation guard and is applied through the tracked Ghostty patch set.

## Upgrade

Install over 0.119.10 without uninstalling. Keep the same bootstrap variant. Package `com.termux`, version code 130. Both variants and all four ABIs retain the existing private signer:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

Existing muxy-signed addons remain compatible. This release does not rebuild addon APKs. An installed Float APK retains its previous embedded terminal libraries and fonts.

## Verification scope

- Debug and release host suites each pass 172 emulator, 51 View, and 36 app tests without failures or skips. The app suite includes eight font-selection, native-graphics, metric, custom-font, and zoom regressions.
- Native PTY subprocess and deterministic interrupted-wait tests pass. A mixed-width output reproducer completes 2,000 resize cycles with alternate-screen transitions and idle compression.
- View release lint passes. The Android instrumentation APK builds.
- All ten signed APKs pass checksum, certificate, manifest, bootstrap, API 21 native import, and 16 KiB ELF alignment verification. Every APK contains the expected font and license bytes.

Android instrumentation and signed in-place upgrade tests were not run. The available Android emulator exits with code 139 before completing boot. Physical-device Doze, OEM process freezing, SSH/network timeouts, and hours-long inactivity remain unverified.
