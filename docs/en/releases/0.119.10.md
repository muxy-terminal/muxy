# muxy 0.119.10

## PTY input responsiveness

Replace the blocking 4 KiB UI-to-PTY queue with a bounded nonblocking input ring. If a child stops reading terminal input, queued typing, paste, or terminal responses no longer wait for queue space on the UI thread.

Accepted writes are copied and delivered in order. The backlog is limited to 1 MiB. A new write that cannot fit is rejected in full with an error instead of blocking or silently truncating input. Write failures and unexpected writer interruption are reported. Session close wakes the writer and does not replay input into another process.

The process-pause test reproduces the old blocking path and verifies resumed delivery after this correction. This is not proof that every physical-device long-idle freeze has the same cause. Ghostty source, idle compression, native thread ownership, and history limits are unchanged.

## Upgrade

Install over 0.119.9 without uninstalling. Keep the same bootstrap variant. Package `com.termux`, version code 129. Both variants and all four ABIs retain the existing private signer:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

The coordinated `muxy.6` addon release updates Float, API, Tasker, and Widget to these shared libraries. Float also surfaces input errors through its normal UI. Styling and Boot keep their standalone behavior. The default keyboard extra key and original Termux tap policy are retained.

## Verification scope

- Debug and release host suites pass 165 emulator, 51 View, and ten app tests per build type. View lint passes.
- Android connection/View/pointer suites complete 69 scenarios on API 21/34/35 without failures. API 21 skips 13 scenarios, including raw-PTY capture because that system image lacks `stty`; API 34/35 skip optional live typing. Some newer-API assertions return early on older Android.
- All ten signed APKs pass certificate, checksum, manifest, embedded bootstrap, API 21 native import, and 16 KiB alignment verification.
- Signed upgrades pass shell/rotation, extra-key editing, and the default keyboard toggle on API 21/35. The API 35 installed-app suite also passes upstream tap/keyboard behavior.
- Float's nine-scenario overlay/PTY suite completes without failures on API 35, with optional live typing skipped. It covers paused-child byte preservation and hidden-overlay recovery. Float also detaches its rendered emulator before disposal to prevent pending draws from accessing a closed native terminal.

Checks preserve existing input and pointer regressions and include native compression convergence and restored history/resumed output.

Physical-device Doze, OEM process freezing, SSH/network timeouts, and hours-long inactivity have not been reproduced. This release does not claim to fix those unconfirmed causes. Details are in [Terminal idle responsiveness](../terminal-idle-responsiveness.md).
